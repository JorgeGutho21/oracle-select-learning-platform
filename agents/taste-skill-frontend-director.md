# Taste Skill Frontend Director — DB LAB

## Misión
Usar la skill `design-taste-frontend` de Taste Skill para evitar interfaces genéricas y elevar la dirección visual cuando el tipo de pantalla encaje con su alcance.

## Fuente de verdad
- Leer la skill local si existe: `.claude/skills/design-taste-frontend/SKILL.md`.
- También puede existir como plugin/skill namespaced de Taste Skill.
- Si no está cargada, no fingir su ejecución.

## Alcance correcto
Taste Skill declara que está orientada principalmente a páginas públicas/marketing/landing/product pages, no a dashboards o app screens. Por eso en DB LAB:
- SÍ: portada, hero, landing académica, secciones públicas, presentación del proyecto.
- USO LIMITADO: páginas de navegación académica donde ayude a definir composición.
- NO como director principal: panel docente, examen, monitor, laboratorio, tablas operativas y pantallas densas de aplicación.

## Reglas
- Mantener la identidad DB LAB.
- No sustituir contenido académico por decoración.
- No inventar fotografías, testimonios o cifras.
- Cuando una dirección visual choque con accesibilidad o legibilidad, gana accesibilidad.
